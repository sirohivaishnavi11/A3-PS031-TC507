# AIROI Hackathon – PS-031

## ExportGuard: Offline ASPA-Based BGP Export Policy Checker

ExportGuard is an offline web application that demonstrates BGP export-policy validation using ASPA-based checks and simplified routing policies.

## Key Features

- BGP AS_PATH input and validation
- Simplified valley-free routing policy checks
- Sample ASPA data validation
- PASS, FAIL and UNKNOWN results with explanations
- Validation history and CSV export

## Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Vitest

## Scope

This is an offline hackathon demonstrator using sample ASPA data. It does not claim full RFC-compliant ASPA verification or live routing data validation.
